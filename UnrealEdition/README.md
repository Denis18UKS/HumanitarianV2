# Humanitarian • Unreal Edition
Целевая версия UE 5.8 для Windows, Visual Studio 2022 с Game development with C++, Windows SDK, встроенный ProceduralMeshComponent. В этой среде проект не компилировался. Humanitarian_UE5.uproject — точка входа. Уровень /Engine/Maps/Entry и GameMode NightMode указаны в Config/DefaultEngine.ini. Геометрия дороги, постройки, модель машины, свет и HUD создаются на старте. Content/Route содержит необходимые данные для упаковки.
 
Открыть .uproject и согласиться с компиляцией модуля. В Play нажать N для нового рейса. W/S тяга и тормоз с реверсом, A/D руль, пробел ручник, C камера, ПКМ обзор, L свет, M схема, Tab груз, Esc пауза, R последняя контрольная точка. В меню V громкость, B чувствительность, G качество, Q выход.
 
На складе остановиться, нажать E для открытия багажника, затем E отдельно для каждой коробки и закрытия. У знаков получателей выполнить E для открытия и E для передачи. После первого адреса следовать по дорожному объезду справа. В гараже E завершает рейс. Сохранение обновляется после грузовых операций. При восстановлении возвращаются положение, состояние груза и ресурсы той точки. Партия ниже 50% даёт частичный успех. При нулевом здоровье или топливе рейс прерывается.
 
Запустить BuildWindows.cmd в Windows. При нестандартной установке задать UE_ROOT равным каталогу UE_5.8. Скрипт запускает UAT с BuildCookRun, Development/Win64 и упаковкой ресурсов. Ожидаемый результат — дерево Build/Windows с Humanitarian_UE5.exe и его зависимостями. Распространять всю папку.
 
Плоская дорога использует кинематическую модель с поворотом, ограничением скорости и swept-коллизией. Подвеска Chaos не подключена. Управление через PlayerController и HUD Canvas. Код в Source/Humanitarian_UE5. Для сравнения физики, освещения, столкновений и FPS требуются запуск и прохождение на Windows.
